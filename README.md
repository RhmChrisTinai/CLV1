### 一.标题修饰符

使用#修饰标题内容，#的数量决定标题大小，一级一个#，最大，之后递减

# 一级标题

## 二级标题

### 三级标题

#### 四级标题 

正文内容直接编辑，换行用<br>某些编辑器或文档中不写br不换

### 二.文本修饰

斜体：一对星号*

*斜体*

粗体：两对星号*

**加粗**

斜粗体：三对星号*

***斜粗体***

删除线（~~划去~~）：两对波浪线~

~~（）~~

凸显：两个反点`

`突出关键`

分割线：分割两段内容，五个星号*

*****

### 三.列表

使用*空格+文本——无序列表，列表可以多级，子集要缩进，可以混合使用，无论是 *还是1，后面都要有空格

* 物理学
  * 原子物理

* 计算机科学
  * socket编程
    * accept
    * bind
    * listen
    * connect
